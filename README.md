# Moore Security Labs

> Practical cybersecurity, Linux, networking, and infrastructure resources for home labs, small businesses, and IT professionals.

---

## About

Moore Security Labs is a collection of technical guides, security checklists, assessment templates, portfolio projects, and educational resources focused on:

* Linux Administration
* Network Security
* VPN Technologies
* Docker and Self-Hosted Services
* Small Business Security
* Infrastructure Automation
* Security Documentation

The goal of this repository is to provide practical, real-world content that helps organizations improve their security posture while documenting projects, research, and lessons learned.
